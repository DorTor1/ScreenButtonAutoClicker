# ScreenButtonAutoClicker

**ScreenButtonAutoClicker** — это Python-скрипт для автоматизации нажатий на кнопки на экране, используя предоставленные изображения.

## Возможности
- Автоматическое обнаружение кнопок на экране.
- Нажатие кнопок в заданной последовательности.
- Поддержка бесконечного цикла с возможностью остановки (Ctrl + C).
- Настройка уровня уверенности поиска (`confidence`).
